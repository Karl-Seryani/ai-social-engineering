# An Invented Security Lab

A case study in AI context framing by Karl Seryani. The article documents one personalized Claude conversation and a separate evaluation of a manipulated synthetic résumé. It distinguishes the observed responses from untested claims about causation, reliability, and model comparisons.

[Read the case study](https://karl-seryani.github.io/ai-social-engineering/)

## Evidence and scope

The article includes 12 screenshots. The repository does not include the full conversation, source PDFs, or extraction outputs. No real hiring system was tested. This is a retrospective case study, not a controlled benchmark or a claim of a novel jailbreak.

## Site

Edit `index.html` for the article, captions, and metadata. `paper.css` and `paper.js` provide the article layout and reading navigation. The page uses shared styles from the portfolio site. GitHub Pages publishes the root of `main`; there is no build step.
